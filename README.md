# Análisis y Predicción de Clientes

Este proyecto tiene como objetivo analizar el comportamiento de clientes y predecir la probabilidad de abandono (churn), con el fin de apoyar la toma de decisiones comerciales.

## Tecnologías usadas
- Python (Pandas, Scikit-learn)
- Power BI

## Análisis realizado
- Identificación de clientes más rentables
- Relación entre reclamos y abandono
- Segmentación de clientes

## Modelo predictivo
Se desarrolló un modelo de clasificación para predecir la probabilidad de churn.

## Resultados
Se encontró que clientes con baja antigüedad y alto número de reclamos presentan mayor riesgo de abandono.

## Conclusión
El análisis permite priorizar estrategias de retención en clientes con mayor probabilidad de churn, optimizando recursos del área comercial.
